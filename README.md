## ⚡ Overview

**HotlineMarcos** is an independent, open-source 2D action game developed with Unity.

The project provides access to its source code and game resources, allowing developers to explore its implementation, experiment with modifications, and contribute to its development.

> **PROJECT STATUS:** Currently under development. Features, content, and gameplay systems are subject to change.

## 🚀 Getting Started

Interested in exploring the project, studying its source code, or experimenting with your own modifications?

Follow the instructions below.

### Requirements

Before getting started, install:

- Unity Hub
- Unity Editor 6000.3.13f1
- Git
- A C#-compatible IDE, such as Visual Studio or Visual Studio Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Geneblis/HotlineMarcos.git
```

**2. Open Unity Hub**

Select `Add project from disk` and navigate to the cloned `HotlineMarcos` directory.

**3. Open the project**

Use the Unity Editor version specified above.

Wait for Unity to import the assets and resolve the project's dependencies.

**4. Run the game**

Open a playable scene in the Unity Editor and press `Play`.

> The first launch may take additional time while Unity imports assets and compiles scripts.

## 🤝 Contributing

**HotlineMarcos is open source, and contributions are welcome!**

Whether you're interested in fixing bugs, improving the codebase, enhancing documentation, or implementing new features, your contributions can help the project evolve.

### How to Contribute

**1. Fork the repository**

Create your own copy of HotlineMarcos using GitHub's Fork button.

**2. Create a new branch**

```bash
git checkout -b feature/my-contribution
```

**3. Make your changes**

Implement your changes and test them using the Unity Editor.

**4. Commit your changes**

```bash
git add .

git commit -m "feat: add new functionality"
```

**5. Push your branch**

```bash
git push origin feature/my-contribution
```

**6. Open a Pull Request**

Describe the changes you've made and submit a Pull Request to the original repository.

### Contribution Guidelines

- Keep code simple, readable, and organized.
- Use descriptive names for classes, methods, and variables.
- Document complex or non-obvious functionality.
- Avoid committing Unity-generated temporary files.
- Test your modifications before submitting a Pull Request.
- Respect third-party asset licenses.

For significant changes, consider opening an [Issue](https://github.com/Geneblis/HotlineMarcos/issues) before beginning development.
